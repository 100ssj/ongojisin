# 온고지신 연구 일반화 웹사이트

전래동화와 현대 생태 문제를 연결한 디지털 기반 온고지신 프로젝트를 다른 교사가 쉽게 이해하고 수업에 적용할 수 있도록 만든 정적 웹사이트입니다.

## 실행

`index.html`을 직접 열어도 핵심 기능이 작동합니다. 로컬 서버로 확인하려면 이 폴더에서 다음 중 하나를 실행합니다.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 구조

- `index.html`: 전체 페이지 구조와 연구 콘텐츠
- `assets/css/main.css`: 디자인 시스템과 반응형 스타일
- `assets/js/data.js`: 프로젝트 및 자료실 데이터
- `assets/js/main.js`: 프로젝트 탭, 검색·필터, 모바일 메뉴 기능

## 자료 추가

`assets/js/data.js`의 `resources` 배열에 항목을 추가합니다. 실제 주소가 없는 자료는 `url: null`로 두면 자동으로 “준비 중” 비활성 상태가 됩니다. 빈 링크(`#`)는 사용하지 않습니다.

## GitHub Pages

별도 빌드 과정이 없는 HTML/CSS/JavaScript 사이트입니다. 저장소 설정에서 배포 폴더를 이 디렉터리로 지정하거나, 이 폴더의 내용을 Pages 배포 위치로 옮겨 사용할 수 있습니다. 내부 경로는 모두 상대 경로입니다.

## 공개 전 확인

- 학생 이름, 얼굴, 학번 등 개인정보 비식별 처리
- 학생 결과물 게시 동의 및 저작권 확인
- 외부 자료의 출처와 온라인 공개 가능 범위 확인
- 생성형 AI 서비스 연령 제한과 이용 약관 확인
- 준비 중인 설문지·검사지의 실제 링크 연결
